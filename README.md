# Algo

Algolenz Route Visualizer — An interactive route optimization and pathfinding algorithm visualizer built with React, TypeScript, Vite, Tailwind CSS, and Leaflet.

## Features

- **Graph & City Map Visualizations**: Interactive pathfinding across custom nodes or real-world city maps.
- **Algorithm Comparison**: Compare execution times, path lengths, and visited nodes across algorithms like Dijkstra, A*, BFS, and DFS.
- **Interactive Controls**: Step-by-step playback, speed adjustments, and custom obstacle placements.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+)
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```
