# Legacy Vanilla JavaScript & CSS Prototype

This folder contains the original single-page prototype of the algorithm visualization platform built using vanilla JavaScript and CSS prior to the full React 18 + TypeScript + Tailwind CSS rewrite.

### Preserved Files:
- `script.js`: DOM-based algorithm execution and step controller.
- `styles.css`: Swiss minimalist design stylesheet with custom layout variables.

*Note: The active production application is implemented in `src/` using React, TypeScript, and Tailwind CSS.*
