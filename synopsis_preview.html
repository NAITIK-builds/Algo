ABSTRACT

Modeled after world-class educational platforms such as VisuAlgo (developed at the National University of Singapore), AlgoLenz is an advanced interactive web-based visualization and learning platform designed to transform complex Data Structures and Algorithms (DSA) into intuitive, step-by-step visual experiences. Computer science algorithms—ranging from graph pathfinding to array sorting—often present steep conceptual hurdles when taught solely through static textbooks or code listings.

AlgoLenz bridges this gap by providing real-time, fine-grained animation controls, synchronized pseudocode execution highlighting, live variable state tracking, and interactive canvas environments. The platform supports graph traversals (BFS, DFS), shortest path algorithms (Dijkstra, A*, Bellman-Ford), sorting algorithms (Bubble, Selection, Insertion, Merge, Quick, Heap), multi-stop waypoint path planning (Traveling Salesperson Problem), and real-world geographic map routing using Leaflet.js. Built with React, TypeScript, Vite, Tailwind CSS, and HTML5 Canvas, AlgoLenz also features side-by-side algorithm benchmarking and interactive self-assessment quiz engines to empower computer science students and educators worldwide.

1. INTRODUCTION

1.1 Objective

Inspired by VisuAlgo, the primary objective of AlgoLenz is to deliver a comprehensive, accessible, and feature-rich interactive algorithm visualizer and educational platform. The core objectives include:

  • VisuAlgo-Style Synchronized Pseudocode: Provide line-by-line code highlighting during live algorithm execution to clearly connect abstract code logic with visual graph/array states.
  • Interactive Control & Data Input: Allow users to pause, step forward/backward, adjust speed, draw custom walls, set terrain weights, generate random inputs, and edit graph node configurations.
  • Multi-Paradigm Algorithm Suite: Cover graph traversals (BFS, DFS), weighted shortest path search (Dijkstra, A*, Bellman-Ford), and comparison/divide-and-conquer sorting (Bubble, Selection, Insertion, Merge, Quick, Heap).
  • Concurrent Multi-Algorithm Comparison: Run multiple algorithms side-by-side on identical input data to benchmark execution runtime (ms), path cost, visited nodes, and array swaps.
  • Spatial & Geographic Routing: Solve multi-stop waypoint path optimization (Traveling Salesperson Problem) and overlay graph algorithms onto real-world Leaflet geographic maps.
  • Self-Assessment & Educational Tools: Provide integrated e-lecture mode summaries and automated quizzes to evaluate algorithm comprehension.

1.2 Scope

The scope of AlgoLenz spans full frontend engineering, algorithm engine design, dynamic canvas rendering, state tracking, and pedagogical tool creation:

  • Graph & Pathfinding Engine: Dijkstra, A* Search, BFS, DFS, and Bellman-Ford algorithms with 2D grid and weighted edge support.
  • Sorting Engine: Bubble, Selection, Insertion, Merge, Quick, and Heap Sort with real-time bar height rendering and swap counters.
  • VisuAlgo Inspector & Pseudocode Panel: Real-time call stack tracking, variable value inspector, and active line-by-line pseudocode highlighting.
  • Map & Waypoint Module: Traveling Salesperson Problem (TSP) solver and Leaflet map geographic route visualization.
  • Analytics & Quiz Engine: Benchmark comparison cards and self-paced assessment quizzes.

3. MODULES

3.1 Modules Name

  1. VisuAlgo-Style Interactive Grid & Graph Visualization Engine
  2. Sorting Algorithm & Array Animation Module
  3. Synchronized Pseudocode & State Inspector Module
  4. Side-by-Side Multi-Algorithm Comparison & Benchmarking Module
  5. Multi-Stop Waypoint & TSP Optimization Engine
  6. Real-World Geographic City Map Routing Engine (Leaflet)
  7. Interactive E-Lecture & Self-Assessment Quiz Module

3.2 Modules Description

  • Interactive Grid & Graph Visualization Engine: Renders a 2D grid canvas supporting start/target node positioning, dynamic wall obstacle drawing, terrain weight painting, and step-by-step animation of search frontiers and shortest paths.
  • Sorting Algorithm & Array Animation Module: Displays array sorting algorithms with dynamic bar charts, highlighting active comparisons, pivot selections, array element swaps, and sorted sub-arrays in real time.
  • Synchronized Pseudocode & State Inspector Module: Displays pseudocode for the active algorithm, dynamically highlighting the currently executing line alongside real-time variable values, queue/stack contents, and step explanations (VisuAlgo standard).
  • Side-by-Side Multi-Algorithm Comparison Module: Concurrently runs two algorithms on identical input setups to benchmark runtime speed (ms), visited node count, path length, array swaps, and theoretical time/space complexity.
  • Multi-Stop Waypoint & TSP Engine: Computes the optimal visiting path across multiple target waypoints using dynamic programming and nearest-neighbor heuristics for the Traveling Salesperson Problem.

4. APPLICATION ARCHITECTURE

  1. User Interface & Control Panel Layer: Built using React functional components, Lucide icons, and Tailwind CSS. Provides top navigation, mode switcher, playback control bar (play/pause, step, speed slider, reset), and input data generators.
  2. State Management & Context Pipeline: Managed via centralized VisualizerContext. Tracks global application state including grid structure, obstacle configurations, selected algorithms, speed factors, step animation queues, and performance metrics.
  3. Algorithmic Engine & Pseudocode Synchronizer: Modular TypeScript engine containing pathfinding (dijkstra.ts, aStar.ts, bfs.ts, dfs.ts, bellmanFord.ts) and sorting (sorting.ts). Generates step snapshots bound to specific pseudocode line index references.
  4. Dual Visualization & Graphics Engine: High-frequency HTML5 Canvas rendering for 2D grids and sorting bar charts, coupled with Leaflet/SVG vector layers for real-world geographic map graphs.
  5. Analytics, Benchmarking & Quiz Engine: Measures execution time (ms), total path distance, visited nodes, array operations, asymptotic complexity metrics ($O(V+E)$, $O(n \log n)$), and processes interactive quiz assessments.

  • Node.js & npm: Package management and execution environment.
