\begin{center}
    {\Large \textbf{ABSTRACT}}
\end{center}
\vspace{0.5cm}

Modeled after world-class educational platforms such as \textbf{VisuAlgo} (developed at the National University of Singapore), \textbf{AlgoLenz} is an advanced interactive web-based visualization and learning platform designed to transform complex Data Structures and Algorithms (DSA) into intuitive, step-by-step visual experiences. Computer science algorithms—ranging from graph pathfinding to array sorting—often present steep conceptual hurdles when taught solely through static textbooks or code listings.

AlgoLenz bridges this gap by providing real-time, fine-grained animation controls, synchronized pseudocode execution highlighting, live variable state tracking, and interactive canvas environments. The platform supports graph traversals (BFS, DFS), shortest path algorithms (Dijkstra, A*, Bellman-Ford), sorting algorithms (Bubble, Selection, Insertion, Merge, Quick, Heap), multi-stop waypoint path planning (Traveling Salesperson Problem), and real-world geographic map routing using Leaflet.js. Built with React, TypeScript, Vite, Tailwind CSS, and HTML5 Canvas, AlgoLenz also features side-by-side algorithm benchmarking and interactive self-assessment quiz engines to empower computer science students and educators worldwide.

\begin{center}
    {\Large \textbf{1. INTRODUCTION}}
\end{center}
\vspace{0.3cm}

\textbf{1.1 Objective}

Inspired by VisuAlgo, the primary objective of AlgoLenz is to deliver a comprehensive, accessible, and feature-rich interactive algorithm visualizer and educational platform. The core objectives include:

\begin{itemize}[leftmargin=2em, itemsep=3pt]
    \item \textbf{VisuAlgo-Style Synchronized Pseudocode:} Provide line-by-line code highlighting during live algorithm execution to clearly connect abstract code logic with visual graph/array states.
    \item \textbf{Interactive Control \& Data Input:} Allow users to pause, step forward/backward, adjust speed, draw custom walls, set terrain weights, generate random inputs, and edit graph node configurations.
    \item \textbf{Multi-Paradigm Algorithm Suite:} Cover graph traversals (BFS, DFS), weighted shortest path search (Dijkstra, A*, Bellman-Ford), and comparison/divide-and-conquer sorting (Bubble, Selection, Insertion, Merge, Quick, Heap).
    \item \textbf{Concurrent Multi-Algorithm Comparison:} Run multiple algorithms side-by-side on identical input data to benchmark execution runtime (ms), path cost, visited nodes, and array swaps.
    \item \textbf{Spatial \& Geographic Routing:} Solve multi-stop waypoint path optimization (Traveling Salesperson Problem) and overlay graph algorithms onto real-world Leaflet geographic maps.
    \item \textbf{Self-Assessment \& Educational Tools:} Provide integrated e-lecture mode summaries and automated quizzes to evaluate algorithm comprehension.
\end{itemize}

\vspace{0.4cm}
\textbf{1.2 Scope}

\textbf{The scope of AlgoLenz spans full frontend engineering, algorithm engine design, dynamic canvas rendering, state tracking, and pedagogical tool creation:}

\begin{itemize}[leftmargin=2em, itemsep=4pt]
    \item \textbf{Graph \& Pathfinding Engine:} Dijkstra, A* Search, BFS, DFS, and Bellman-Ford algorithms with 2D grid and weighted edge support.
    \item \textbf{Sorting Engine:} Bubble, Selection, Insertion, Merge, Quick, and Heap Sort with real-time bar height rendering and swap counters.
    \item \textbf{VisuAlgo Inspector & Pseudocode Panel:} Real-time call stack tracking, variable value inspector, and active line-by-line pseudocode highlighting.
    \item \textbf{Map & Waypoint Module:} Traveling Salesperson Problem (TSP) solver and Leaflet map geographic route visualization.
    \item \textbf{Analytics & Quiz Engine:} Benchmark comparison cards and self-paced assessment quizzes.
\end{itemize}

\begin{center}
    {\Large \textbf{3. MODULES}}
\end{center}
\vspace{0.3cm}

\textbf{3.1 Modules Name}

\begin{enumerate}[leftmargin=2em, itemsep=4pt]
    \item VisuAlgo-Style Interactive Grid \& Graph Visualization Engine
    \item Sorting Algorithm \& Array Animation Module
    \item Synchronized Pseudocode \& State Inspector Module
    \item Side-by-Side Multi-Algorithm Comparison \& Benchmarking Module
    \item Multi-Stop Waypoint \& TSP Optimization Engine
    \item Real-World Geographic City Map Routing Engine (Leaflet)
    \item Interactive E-Lecture & Self-Assessment Quiz Module
\end{enumerate}

\vspace{0.4cm}
\textbf{3.2 Modules Description}

\begin{itemize}[leftmargin=2em, itemsep=8pt]
    \item \textbf{Interactive Grid \& Graph Visualization Engine:} Renders a 2D grid canvas supporting start/target node positioning, dynamic wall obstacle drawing, terrain weight painting, and step-by-step animation of search frontiers and shortest paths.
    \item \textbf{Sorting Algorithm & Array Animation Module:} Displays array sorting algorithms with dynamic bar charts, highlighting active comparisons, pivot selections, array element swaps, and sorted sub-arrays in real time.
    \item \textbf{Synchronized Pseudocode & State Inspector Module:} Displays pseudocode for the active algorithm, dynamically highlighting the currently executing line alongside real-time variable values, queue/stack contents, and step explanations (VisuAlgo standard).
    \item \textbf{Side-by-Side Multi-Algorithm Comparison Module:} Concurrently runs two algorithms on identical input setups to benchmark runtime speed (ms), visited node count, path length, array swaps, and theoretical time/space complexity.
    \item \textbf{Multi-Stop Waypoint & TSP Engine:} Computes the optimal visiting path across multiple target waypoints using dynamic programming and nearest-neighbor heuristics for the Traveling Salesperson Problem.
    \item \textbf{Real-World City Map Routing Engine:} Overlays graph algorithms on interactive Leaflet geographic maps to demonstrate practical navigation and road-network routing.
    \item \textbf{E-Lecture & Self-Assessment Quiz Module:} Provides structured educational summaries, theoretical complexity breakdowns, and interactive quiz questions to test user understanding.
\end{itemize}

\setcounter{page}{6}

\begin{center}
    {\Large \textbf{4. APPLICATION ARCHITECTURE}}
\end{center}
\vspace{0.4cm}

\begin{enumerate}[leftmargin=2em, itemsep=10pt]
    \item \textbf{User Interface & Control Panel Layer:} Built using React functional components, Lucide icons, and Tailwind CSS. Provides top navigation, mode switcher, playback control bar (play/pause, step, speed slider, reset), and input data generators.
    
    \item \textbf{State Management & Context Pipeline:} Managed via centralized \texttt{VisualizerContext}. Tracks global application state including grid structure, obstacle configurations, selected algorithms, speed factors, step animation queues, and performance metrics.
    
    \item \textbf{Algorithmic Engine & Pseudocode Synchronizer:} Modular TypeScript engine containing pathfinding (\texttt{dijkstra.ts}, \texttt{aStar.ts}, \texttt{bfs.ts}, \texttt{dfs.ts}, \texttt{bellmanFord.ts}) and sorting (\texttt{sorting.ts}) routines. Generates step snapshots bound to specific pseudocode line index references.
    
    \item \textbf{Dual Visualization & Graphics Engine:} High-frequency HTML5 Canvas rendering for 2D grids and sorting bar charts, coupled with Leaflet/SVG vector layers for real-world geographic map graphs.
    
    \item \textbf{Analytics, Benchmarking & Quiz Engine:} Measures execution time (ms), total path distance, visited nodes, array operations, asymptotic complexity metrics ($\mathcal{O}(V+E)$, $\mathcal{O}(n \log n)$), and processes interactive quiz assessments.
\end{enumerate}
